# Public test feedback

Please open an issue with the following fields. Remove private repository names, source code, credentials, and customer data before posting.

```text
DSH version:
Model route and reasoning effort:
Original task text (sanitized):
Classifier JSON (`task_router_status`):
Expected task label:
Was the selected mode actually used? How was this verified?
Acceptance test or observable outcome:
Would another mode likely have done better? Why?
```

Useful reports are classification mistakes and task outcomes. Trace wording such as `We need` or `Let me` is diagnostic metadata, not proof of ability or an internal expert switch.
